# 🎉 Bebi Birthday Surprise 💕

An interactive birthday surprise webpage with animations, balloons, photos, and heartfelt messages.

## 🌐 Live Link
**[Open the Birthday Surprise](https://cbnc1108-droid.github.io/bebi-birthday-surprise/)**

## ✨ Features
- 🎈 Interactive balloon pop game
- 📸 Photo gallery
- 🎁 Gift reveal animation
- 🎂 Cake wish interaction
- 🎉 Confetti celebrations
- 💕 Floating hearts
- 📱 Fully mobile responsive
- ✨ Smooth animations and transitions

## 🎯 How to Use
1. Click the link above to open the page
2. Follow the interactive elements through each screen
3. Pop the balloons, open gifts, make a wish, and unlock the final message
4. Share with your special someone! 💌
